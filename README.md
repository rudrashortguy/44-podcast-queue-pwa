# AudioPod - Offline Podcast Notes Queue

Organize your podcast episode queue, take timestamped show notes, and track listening progress.

## Features
- Podcast episode queue
- Timestamped note-taking
- Playback progress tracker
- Export show notes

## Tech Stack
- **Vite** & **React 18** with TypeScript
- **Tailwind CSS** for responsive mobile-first styling
- **Workbox / Vite PWA Plugin** for offline caching & service worker lifecycle

## Development
```bash
npm install
npm run dev
```
